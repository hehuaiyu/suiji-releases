# 随记

轻量的 Windows 随手记录与待办工具，支持会话整理、Markdown、图片附件和重要内容置顶。

## 下载

[下载最新 Windows x64 安装包](https://github.com/hehuaiyu/suiji-releases/releases/latest)

在发布页的 Assets 中选择 `Suiji-Setup-版本号-x64.exe`。首次安装支持应用内更新的版本后，可在「设置 → 随记更新」检查、下载并重启更新。

## 更新

- 启动后可在后台检查新版本，也可以关闭这项设置。
- 下载和重启安装由你手动确认；关闭窗口或退出应用不会自动安装。
- 更新前先保存草稿，正在保存、导入或导出的任务完成后再更新。
- 更新失败可重试，或从发布页下载完整安装包覆盖安装。
- 安装升级保留已有记录、附件和设置。重要资料建议定期使用应用内导出备份。
- 目前提供 Windows x64 版本；安装包暂未使用商业代码签名证书。

此公开仓库用于分发安装包、更新元数据和版本说明。下载无需 GitHub 登录。程序数据保存在你的电脑上，更新检查不会上传记录和附件。
